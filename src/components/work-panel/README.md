# 工作面板

核心界面采用纯黑底色：440×420 展开列表、摘要胶囊、36px 可见来源球（48×48 原生命中窗口）。

- 顶部图钉可切换置顶，实心表示已固定到屏幕顶部；切换时保留当前展开页。手动取消本轮自动置顶后，本轮任务结束前不重复抢回，后续任务仍遵循原有自动置顶偏好。
- 置顶时面板与胶囊顶部两角为直角、底部保持圆角；取消置顶恢复四角圆润，收起光球始终保持圆形。
- 菜单图标在任务列表与 800×260 组件页之间切换；组件页保持顶部停靠，再点菜单或按 Escape 返回列表。胶囊和球的收起入口保留在标题栏与来源球。
- 组件页包含今日 Token 用量、网络环境和两个预留位置。四个组件横向排布；宽度不足时依次改为双列、单列滚动。真实组件统一使用“标题—主结果—两列明细”层级，占位组件降低对比度并居中收拢。
- 今日用量按本地日期汇总本机已采集的各来源记录，显示输入、输出及总量；缓存与思考 Token 不重复加算。0 表示当日没有已记录用量，读取失败显示不可用。鼠标悬停数值可看完整数量与统计范围。
- Windows 网络类型来自系统首选连接配置；海外网络通过 HTTPS HEAD 同时检查 `chatgpt.com` 和 `www.google.com`（单站 2.5 秒超时）。任一站点完成 DNS、TLS 并返回有效网页响应即显示“可达”，界面只显示延迟，不展示命中的站点；两站都失败才显示“不可达”。该结果不代表账号、地区或具体功能均可使用。其他平台尚未接入原生网络类型读取时显示“未识别”。
- 组件打开时刷新，每 30 秒更新一次，用量采集事件触发额外刷新；收起、切页或页面隐藏时停止探测，关闭页面清理监听。浏览器演示明确提示桌面端可用，不编造实时值。

- 字体和纯黑配色限定在 WorkPanel 内，不影响设置页。
- 任务标题 14px / 500，来源与时间 11px / 400（#969696），状态 12px；64px 同级行。悬停使用 14% 白色背景，从列表左缘铺满整行至滚动条前，文字与 Logo 位置和颜色不变。
- 列表连续纵向滚动，右侧为 6px 细滚动条；无翻页控件或条数截断。阅读期间现有行保持位置，新任务自动追加，重新展开时按最近时间排序。
- 来源球无执行中任务时，外环以 3.2 秒周期柔和呼吸；只有至少一项任务正在执行时，独立的 3px 亮点才以 1.8 秒周期沿环绕行。待确认、失败、已完成（包括未读）不触发转圈；减少动态效果时使用静态亮环，仅执行中显示静态亮点。Logo 保持不动，来源稳定，多来源用 +N 表示，任务数量按全部任务统计。
- 保留原生停靠、拖动、通知策略和窗口大小同步。球内 Logo 不跟随开合旋转。
- 展开列表的顶部标题栏和来源球可拖动，任务行保留点击与滚动；拖动松手后保持列表展开。置顶模式仍遵循原来的顶部归位规则。
- 开合使用明确的像素尺寸和共享锚点：顶部保持中心，左右停靠保持对应边缘。列表展开约400ms、折叠约340ms，胶囊缩球约440ms（含重叠的球体移动）；相同状态复用一个文字元素并保持字重与透明度，来源名称单独显隐；不同文案先退后入，避免文字叠影。原生窗口在退出动画结束后才裁小。
- 浏览器预览保持固定动画画布，避免宿主尺寸变化造成横跳；它不能替代桌面原生拖动与系统窗口表现的验收。
- Windows 使用固定 1040×420 的 WebView 绘制区域，球锚点固定在横向 520。球、胶囊与列表仅改变外层窗口裁切和子窗口偏移，常规开合不再调用 WebView2 `SetBounds`；鼠标命中范围仍是实际外框大小。仅初始化、DPI 改变或需要更高画布时调整绘制区域。
- 组件页沿用该固定绘制区域。尺寸动画是有意保留的例外：真实外框须按同一锚点裁切，文字保持原字号，不能用缩放整个面板替代。
- 此原生模式由后端 `app_meta.fixedOverlaySurface` 告知前端，避免开发热更新时新旧原生布局混用。Mac 与浏览器预览继续使用原有画布规则。
- 点击任务和标记已读调用已有后端接口；浮层底部说明及设置入口已移除，设置仍可通过原有托盘／菜单打开。

`http://localhost:1420/` 为同组件演示，使用示例任务；Tauri overlay 使用实际任务数据。
