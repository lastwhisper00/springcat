# Tool logos

Monochrome product marks used to identify the tool that owns the active task.

- `codex.svg` — Codex
- `cursor.svg` — Cursor
- `grok.svg` — Grok / Grok CLI
- `gemini-cli.svg` — Gemini CLI
- `workbuddy.svg` — WorkBuddy

The Codex, Cursor, Grok, and Gemini CLI SVG shapes are vendored from [LobeHub Icons](https://github.com/lobehub/lobe-icons) v1.94.0 (MIT). The WorkBuddy SVG is vendored unchanged from the [official WorkBuddy site](https://copilot.tencent.com/work/). Product names and marks remain the property of their respective owners. Keep the paths and proportions unchanged; the UI applies color through a CSS mask to monochrome assets and renders the WorkBuddy product icon in its original colors.
