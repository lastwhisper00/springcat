# Tool logos

Monochrome product marks used to identify the tool that owns the active task.

- `codex.svg` — Codex
- `cursor.svg` — Cursor
- `grok.svg` — Grok / Grok CLI
- `gemini-cli.svg` — Gemini CLI
- `workbuddy.svg` — WorkBuddy
- `marvis.svg` — Marvis

The Codex, Cursor, Grok, and Gemini CLI SVG shapes are vendored from [LobeHub Icons](https://github.com/lobehub/lobe-icons) v1.94.0 (MIT). The WorkBuddy SVG is vendored unchanged from the [official WorkBuddy site](https://copilot.tencent.com/work/). The Marvis mark is a compact vector adaptation of the product icon bundled with the local Marvis desktop app. Product names and marks remain the property of their respective owners. The UI applies color through a CSS mask to monochrome assets and renders the WorkBuddy and Marvis product icons in their original colors.
