# Core work-panel font

`NotoSansSC-VF.ttf` is Noto Sans SC with a variable weight axis of 100–900. The complete font is bundled for arbitrary Chinese task titles. Its SIL Open Font License is included as `OFL.txt`.

Copied from the reviewed design's font asset. SHA-256: `763146584cf0710223441356b4395e279021b0806c196614377a7a0174ae074a`.

The `SpringCat Sans` CSS alias is applied only inside `WorkPanel.svelte`. Settings and global font styles remain unchanged.
