# AI 桌面任务宠物：项目描述与技术选型

> 文档版本：v1.1  
> 更新日期：2026-08-13  
> 项目代号：`springcat-ai` / `TaskPet`  
> 目标平台：Windows 10/11、macOS 12+  
> 本版重点：工作模式 / 宠物模式；MVP 先实现工作模式，宠物形态后置  
> 实现步骤见 [springcat-ai-v1.md](./springcat-ai-v1.md)

## 1. 项目概述

SpringCat 是一个常驻桌面的轻量 AI 任务提醒应用。它统一展示 Codex、Grok CLI、Cursor 等 AI 编程工具的任务状态，并提供两种展示形态：

- **工作模式（MVP 先做）**：不使用宠物形象，用一块可拖动、可吸附的工作面板（紧凑状态卡片，不是全屏遮罩式模态）贴在屏幕顶部或左右侧边。
- **宠物模式（后续再做）**：一只可吸附在屏幕边缘的桌面宠物，用表情、状态灯和消息气泡提醒。

用户提交耗时任务后，可以离开原来的对话界面继续工作。应用在后台观察任务，在完成、失败或需要人工确认时发出提醒。

核心价值：

> 把多个 AI 工具的后台任务状态，转化为一个安静、低干扰、可长期停留在桌面边缘的提醒层。工作模式优先保证可用性；宠物模式在同一套任务模型上提供更有情感的陪伴体验。

### 1.1 非目标（工作模式 MVP）

- 不实现宠物形象、Rive 角色动画或宠物皮肤。
- 不复制 Codex / Cursor / Grok 的完整聊天界面。
- 不读取或上传完整项目代码。
- 不做养成、商城、社交或云同步。
- 不承诺盖过全屏游戏。
- 工作面板不是阻塞整屏的模态。

## 2. 展示模式

```ts
type PresentationMode = "work" | "pet";
```

默认 `work`。两种模式共用事件、仓库、优先级和通知策略，只替换展示层。领域层不得出现宠物专用字段。

## 3. 状态优先级

```text
waiting > failed > completed-unread > running > idle
```

由纯函数计算：

```ts
function deriveSurfaceState(tasks: TaskItem[]): SurfaceState
```

工作模式表现：

- 执行中：暖黄状态点，不弹摘要
- 等待确认：琥珀色，探出且不自动消失
- 已完成：薄荷绿，约 5 秒收起并留未读点
- 失败：珊瑚红，摘要不自动消失

## 4. 技术栈

```text
桌面外壳        Tauri 2
前端            Svelte 5 + TypeScript + Vite
工作面板 UI     HTML / CSS（MVP 唯一展示层）
宠物动画        Rive Canvas Lite（仅宠物模式，后置）
本地核心        Rust
本地存储        SQLite
```

事件链路：工具 hooks → `springcat-bridge` → inbox 文件 → Rust 监听/规范化/入库 → Tauri event → Svelte 展示层。

## 5. 窗口与吸附（工作模式）

- 默认一个常驻 WebView，约 `360×48` 收起。
- 可吸附 **顶部 / 左侧 / 右侧**，避开任务栏、Dock、菜单栏。
- 不支持底部吸附。
- 设置窗口按需创建，关闭即销毁。

## 6. 范围

**MVP：** Windows、工作面板、五种状态、三种适配器、任务列表、静音/专注、托盘、开机启动、7 天历史。

**v1.0：** 宠物模式、模式切换、macOS DMG、多屏记忆、声音、自动更新。

更细的逐步任务以 [springcat-ai-v1.md](./springcat-ai-v1.md) 为准。
