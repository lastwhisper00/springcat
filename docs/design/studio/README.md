# SpringCat · 产品设计全览

Concept 09 · Type：更舒适的中文排版，整行半透明悬停反馈。

本轮使用自托管的完整 Noto Sans SC 可变字体，界面族名为 SpringCat Sans；支持真实 100–900 字重，保留正常字距。任务标题为 15px / 500 / 22，来源、时间与状态为 13px / 400 / 20。两行间距 2px、上下各 10px 内距，仍保持 64px 行高；左右各留 10px 内距。

列表悬停只显示整行半透明背景：深色主题白色 6%，浅色主题深墨色 #141C26 的 4%；按下分别为 9% 和 7%。文字、图标、状态颜色完全不变，背景过渡 120ms；减少动态效果时即时切换。

展开头部的球内放当前执行来源的真实 Logo，默认混合示例仅 Cursor 在执行，因此显示 Cursor。球使用中性实底，深色主题配浅色 Logo，浅色主题配深色 Logo；运行时只有外环微亮，Logo 始终清晰。旁边“N 项进行中”统计全部任务，包含其他分页。

多个不同来源执行时，保持当前代表来源，只要它仍在执行就不自动切换；其停止后再切换下一来源。右上角 +N 表示其他运行来源数，不是任务数。同一来源多任务只显示一个 Logo，无 +N。来源全名通过提示和可读描述提供。没有执行时保留上一来源 Logo、熄灭外环，并显示“暂无进行中”；首次加载可取最近任务来源。

展开头部与摘要采用 28px 球 / 16px Logo；顶部收起采用 22px / 13px；侧边收起采用 28px / 16px，总窗口仍为 36px。刘海 6px 静默下沿仅用 4px 光点，悬停或展开才展示完整 Logo。底部绿色仍只表示连接；减少动态效果保留静态 Logo 与执行外环。

展开面板中的待确认、进行中、已完成与失败使用相同的行结构、字号、字重和背景。右侧状态文字与小色点表达差异。多个待确认各占一行，点击对应任务后才展开具体请求说明；标记已读不改变待确认状态。

默认示例包含五条任务，其中三条待确认、一条进行中、一条已完成。每页最多五条，更多任务提供上一页、下一页与总数，也可通过“全部任务”进入完整工作台。阅读期间保留任务序位与当前页；重新打开或主动刷新时再按最近更新时间排列。

已确认的专业配色与空间约束保留：顶部 128×30、摘要 248×40、侧边球 36×36、展开宽 520、左右内边距 24。非分页时高度随内容自然变化；五条任务约 470 高。分页时保留列表高度，使前后页均约 506 高，不设置内部滚动区。文字操作、细箭头和实际来源图标延续上一版。

## 打开方式

双击 `index.html` 在浏览器打开，无需安装依赖或联网。点击画板查看标注，双击或点击「放大查看」阅读细节。窄窗口单击即可放大。

`prototype.html` 是独立可操作的交互演示。其数据、记录与结果都仅限本页，未连接真实 AI 工具；位置、主题和减少动态效果也不修改系统设置。

## 形态层级

1. 常驻入口：普通顶部约 128×30；侧边可见球 36×36；刘海下沿按硬件安全区域计算。
2. 摘要胶囊：248×40 起，用一行汇总当前任务状态，不随待确认数量扩大。
3. 展开面板：桌面宽 520，两侧留白 24；所有任务使用同级行，高度由内容自然决定。每页最多五条，更多任务明确分页；完整列表和长内容进入工作台。
4. 完整工作台：独立窗口承载历史、设置和用量。关闭工作台保留常驻入口。

设计画板本身尺寸与产品组件逻辑尺寸不同。画板内有组件尺寸与定位说明；macOS 按逻辑点、Windows 按设备无关尺寸落地，并需验证系统缩放、多屏、全屏、菜单栏与刘海。

## SVG 与 Figma

- `artboards/`：88 块画板 × 3 套主题，共 264 个独立 SVG。
- `sheets/`：8 组页面 × 3 套主题，共 24 个排版后的整页 SVG。
- 总览中的「下载整页 SVG」用于一次导入一组画板；每块画板也可单独下载。
- 可将 SVG 拖入 Figma 继续整理。当前交付不是 `.fig` 文件，也未创建 Figma 云端文档；原生组件、变量绑定、Auto Layout 与 Figma 原型连线需在导入后建立。
- SVG 保留矢量结构和文本元素，但最终字体、文字处理与分组取决于导入工具，请导入后核对。总览内联 SVG 使用随包自托管的字体；独立 SVG 声明 SpringCat Sans / Noto Sans SC，不逐张嵌入字体。独立打开或导入 Figma 前请安装 Noto Sans SC，以保持字形与排版一致。

## 交互演示

五种位置、三套主题、单个与多个待确认、仅待确认且无运行、全部完成示例、分页、业务事件、悬停摘要、点击开合、反向操作、Escape、拖动吸附与取消、任务详情、来源打开成功／失败和导航切换均可操作。

## 文件结构

- `index.html` / `design.css` / `design.js`：设计总览。
- `prototype.html` / `prototype.css`：离线交互演示及统一样式。
- `fonts.css` / `assets/fonts/`：完整 Noto Sans SC 可变字体、字体声明及 SIL Open Font License。
- `design-data.js` / `screen-index.json`：画板与标注。
- `visual-tokens.json`：主题、尺寸、文字、组件和动效规范。
- `interaction-spec.json`：24 条交互流程与约束。
- `build-design.mjs`：生成 SVG 与总览数据；执行 `node build-design.mjs` 重新生成。

所有用量是示例。Token 构成中缓存是输入子项，推理是输出子项，不能重复累加。API 等价金额仅为版式示意，不等于真实订阅账单。

## 验收与集成边界

Concept 09 已实测：自托管字体加载成功，完整字体文件为 17,773,244 字节、字重轴 100–900；任务标题为 15px / 500 / 22，辅助信息为 13px / 20，全部任务行保持 64px。390px 视口下展开面板宽 323px，头部和列表无内部横向或纵向溢出，示例标题完整可见。

实际指针悬停验证了浅色整行背景 `rgba(20, 28, 38, .04)`，文字仍与普通行同色；深色文字也保持不变，背景使用白色 6%。检测提示仍限于外围小字、装饰背景、原有尺寸动画和用户要求保留的来源球外环。

- Concept 06–08 的同级列表、分页、来源身份、执行总数、详情返回焦点与窄窗口检查作为回归基线，本轮字体与悬停结果以上述实测为准。
- 已重新生成并通过校验：4 个 JavaScript 源、3 个 JSON 文件、264 个独立 SVG 与 24 个整页 SVG；字体不嵌入每张 SVG。
- 字体随离线包提供；原型与总览通过相对路径加载，无需联网。独立 SVG 与 Figma 的字体匹配由导入环境决定。
- 范围与设计决策见 `FOCUS-NOTES.md`。示意背景的弱化文字仅作空间参照；外壳变形仍为浏览器原型。
- 原生窗口、真实多屏、点击穿透、系统安全区、按屏幕高度自动减少每页容量与各来源工具连接不在这个浏览器原型中；集成后另行验证。
